# آية محمد بريمان — هدية عيد الميلاد 🤍

نسخة كاملة من الموقع بآخر تعديلاته، جاهزة للرفع إلى GitHub Pages.

## التفاصيل المحفوظة

- النص العربي واتجاه العرض من اليمين إلى اليسار.
- خط Baloo Bhaijaan 2 بخمسة أوزان، وملفات الخطوط محلية.
- القطة والفيونكة والفراشات والزهور والرسومات المتجهة والتفاصيل الورقية.
- ظرف الرسالة ونافذة التهنئة.
- خمس زهور مختلفة مع خمس أمنيات تفاعلية.
- جزء البرمجة ومفاجأة الاحتفال.
- التنسيق المتجاوب للشاشات الصغيرة وتفضيلات تقليل الحركة.
- الاسم الكامل، وحذف المرسم وعبارات الصداقة كما في النسخة الأخيرة.

## التشغيل محليًا

افتح `index.html` في المتصفح مباشرة. لا توجد حزم npm أو خطوة بناء أو مفاتيح API.

يمكن أيضًا تشغيل خادم محلي اختياريًا:

```sh
python -m http.server 8000
```

ثم افتح http://localhost:8000

## الرفع إلى GitHub Pages

1. أنشئ مستودعًا جديدًا باسم تختاره، مثل `aya-birthday`.
2. فك ضغط الأرشيف وارفع **محتويات مجلد aya-birthday** إلى جذر المستودع، بحيث يكون `index.html` في الجذر مباشرة. لا ترفع ملف ZIP نفسه فقط.
3. احتفظ بجميع ملفات الخطوط وملفات CSS وJavaScript بجوار `index.html`.
4. افتح Settings → Pages.
5. تحت Build and deployment اختر Source: Deploy from a branch.
6. اختر الفرع `main` والمجلد `/(root)` ثم Save.
7. سيظهر رابط الموقع في صفحة Pages بعد اكتمال النشر.

جميع روابط الموارد نسبية، لذا يعمل الموقع تحت مسار المستودع أيضًا.

المرجع الرسمي: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## الملفات

- `index.html`: المحتوى والرسومات SVG المدمجة.
- `style.css`: الألوان والتخطيط والحركة والاستجابة للشاشات.
- `app.js`: الزهور والرسالة ومفاجأة الاحتفال.
- `fonts.css` وملفات `.ttf`: الخطوط المحلية.
- `.nojekyll`: تعطيل معالجة Jekyll غير المطلوبة.

## الدومين المخصص

هذا التصدير لا يغير استضافة الموقع الحالي أو سجلات DNS. لربط `ayabriman.run.place` باستضافة GitHub Pages لاحقًا، يجب ضبط Custom domain في GitHub وتحديث سجلات DNS وفق قيم GitHub، بدل قيم الاستضافة الحالية. لم يُضمّن ملف CNAME كي لا يُفعّل نقل الدومين تلقائيًا.

مرجع GitHub الرسمي: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
